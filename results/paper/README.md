# Paper Result Summaries

This directory contains compact experimental summaries used to regenerate the
paper's table and figure data without the full prediction artifacts under
`outputs/`.

The experimental summaries are generated by the experiment pipeline and collected into this directory using:

```bash
python -m report.collect_results
```

The generated/ directory contains aggregated CSV data underlying the paper's tables and figures. These files can be regenerated from the experimental results stored in the other directories under results/paper/.

## Source Directories

| Directory | Contents |
|---|---|
| `table_1/` | Table 1 selection-regret summaries |
| `table_2_3_4/` | Shared inputs for Tables 2, 3, and 4 |
| `table_6/` | Table 6 structure-search summaries |
| `figure_3/` | Figure 3 RQ3 control results |
| `figure_4/` | Figure 4 neighbourhood and capacity sweeps |
| `k_sensitivity/` | Candidate-set size sensitivity results |
| `tuning/` | Search results behind `configs/corrector_optimizers.csv` |
| `generated/` | Rebuilt table and figure CSV data |

## Regenerating Results

From the repository root, run:

```bash
python -m report.make_tables
python -m report.make_figure_data
```

To regenerate selected results only:

```bash
python -m report.make_tables --tables 1 6
python -m report.make_figure_data --figures 3 4a 4b
```

These files support inspection and regeneration of the reported results. They
do not constitute an end-to-end rerun of the MEC server-selection experiments.
